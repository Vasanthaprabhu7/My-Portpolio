# G. T. Vasanthaprabhu - Personal Portfolio Website

A modern, high-performance personal portfolio website built with HTML5, Vanilla CSS3, and JavaScript, designed to showcase Vasanthaprabhu's expertise in **Generative AI, Machine Learning, Python, SQL, and Full-Stack Web Development**.

## 🚀 Live Demo & Features

- **Obsidian Dark & Crisp Light Mode**: Smooth theme toggling with persistent user preference in `localStorage`.
- **Interactive Constellation Canvas**: Dynamic particle constellation reacting to mouse movement.
- **Dynamic Typewriter**: Highlighting AI/ML, Full-Stack, and Data Analytics competencies.
- **Bento Grid Layout**: Elegant presentation of Career Objective, Education (R.V.S. College of Engineering, CGPA 8.33), Languages, and Highlights.
- **Interactive Project Deep-Dive Modals**: In-depth breakdowns of architectural solutions, problem statements, and tech stacks for:
  - *Real Time Smart Blood Donation Coordination System*
  - *Social Media Analytics Using Python*
  - *Customer Churn Prediction Platform*
- **One-Click Copy Buttons**: Instant copy-to-clipboard for Email (`vasanthaprabhu3072004@gmail.com`) and Phone (`6382368204`) with interactive toast alerts.
- **Interactive Resume Modal**: In-browser preview of the complete formatted resume with a one-click **Print / Save as PDF** feature (`@media print` optimized).
- **Responsive Mobile & Desktop**: Custom glassmorphic navbar with mobile hamburger menu and scrollspy navigation.

## 💻 Running Locally

You can run this project locally using any simple HTTP server:

### Using Python:
```bash
python -m http.server 3000
```
Then open [http://localhost:3000](http://localhost:3000) in your web browser.

### Using Node.js:
```bash
npx serve .
```

### Direct Open:
You can also directly double-click `index.html` to open it in any modern browser!
